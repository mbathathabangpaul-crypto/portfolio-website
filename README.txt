# 🚀 Thabang Mbatha Portfolio Website

A modern, responsive, and accessible portfolio website showcasing my journey from Customer Support Consultant to Data Engineer.

Built with HTML, CSS, and JavaScript, this portfolio demonstrates frontend development fundamentals while reflecting the principles I apply in data engineering: clean architecture, maintainability, automation, and user\-focused design.



## 👨‍💻 About Me

I am **Thabang Paul Mbatha**, a graduate in Software Engineering/Data Engineering at WeThinkCode and a Jr Data Engineer at Mukuru.

My background spans customer support, hospitality, industrial operations, and software engineering, giving me a unique perspective on solving business problems through technology and data.

This portfolio was created to showcase:

- Technical projects
- Data engineering skills
- Professional experience
- Certifications
- Career progression
- Continuous learning journey

# 🎨 Design Principles

This project follows several key design principles:

### Consistency

Reusable design system powered by CSS variables.

### Accessibility

All users should be able to navigate and consume content comfortably.

### Performance

Avoid unnecessary frameworks and dependencies.

### Maintainability

Modular structure that is easy to expand and update.

### Responsiveness

Optimized for:

- Desktop
- Tablet
- Mobile
